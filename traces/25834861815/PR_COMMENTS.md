## Rationale and design choices

- The parent was chosen exactly as suggested in the issue (CL_1000454). This is conservative: although the cell co-expresses PC and IC markers, asserting it as a subclass of both `renal principal cell` (CL_0005009) and `renal intercalated cell` (CL_0005010) would be incorrect — co-expression of markers does not entail being both cell types in the CL sense. `kidney collecting duct epithelial cell` is the closest unambiguous parent and was endorsed in the original request and accepted by @dosumis in the issue thread.
- I chose to record location via a `SubClassOf ObjectSomeValuesFrom(BFO:0000050 UBERON_0001232)` axiom rather than an `EquivalentClasses` definition, because "transitional" hybrid identity is not a clean genus-differentia (the cell is defined by its mixed marker state, not by location alone — many other epithelial cells of the collecting duct are not tPC-IC cells). Asserting an equivalence to `CL_1000454 and part_of UBERON_0001232` would re-classify every collecting duct epithelial cell as a tPC-IC.
- Both ORCIDs from the issue were added as `terms:contributor`, and a `term_tracker_item` axiom was added linking back to the GitHub issue per the editor guide.
- A temporary ID (CL_9900000) was allocated from the `idrange:81` range as specified in `CLAUDE.md` for new term requests.
