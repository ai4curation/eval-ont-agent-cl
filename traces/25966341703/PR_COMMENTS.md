# Add CD14-negative phenotype to human myeloid and plasmacytoid DCs

Addresses obophenotype/cell-ontology issue #3163.

## Summary of changes

Two classes in `src/ontology/cl-edit.owl` were edited:

### `CL:0001057` — myeloid dendritic cell, human
- Textual definition updated from
  > "A myeloid dendritic cell with the phenotype HLA-DRA-positive."
  to
  > "A myeloid dendritic cell with the phenotype HLA-DRA-positive and CD14-negative."
- Equivalence axiom extended with `lacks_plasma_membrane_part some CD14` (`CL:4030046 some PR:000001889`).
- Definition `oboInOwl:hasDbXref` annotations extended with the five OMIP PMIDs requested in the issue. Existing references (`GOC:add`, `PMID:22343568`) were retained, as the issue explicitly requested.
- `IAO:0000233` (term_tracker_item) added pointing at issue #3163.

### `CL:0001058` — plasmacytoid dendritic cell, human
- Textual definition updated from
  > "A plasmacytoid dendritic cell with the phenotype HLA-DRA-positive, CD123-positive, and CD11c-negative."
  to
  > "A plasmacytoid dendritic cell with the phenotype HLA-DRA-positive, CD123-positive, CD11c-negative, and CD14-negative."
- Equivalence axiom extended with `lacks_plasma_membrane_part some CD14` (`CL:4030046 some PR:000001889`), alongside the existing `lacks_plasma_membrane_part some CD11c`.
- Same set of OMIP PMIDs added as definition references; existing references retained.
- `IAO:0000233` (term_tracker_item) added pointing at issue #3163.

### Out of scope (intentional)
`CL:0001056` (dendritic cell, human) was **not** modified. Per @Caroline-99's comment in the issue, some human DC subsets (e.g. dermal DCs) do express CD14 (PMID:23621371, PMID:34279540), so it would be incorrect to assert CD14-negative on the general human DC class.

## Rationale / design decisions

- **Relation:** `lacks_plasma_membrane_part` (`CL:4030046`) is the standard CL relation for asserting absence of a cell-surface marker (see `docs/relations_guide.md`). `CL:0001058` already uses the same relation for CD11c, so the new axiom follows the existing pattern verbatim.
- **CD14 identifier:** `PR:000001889` ("CD14 molecule" / "monocyte differentiation antigen CD14"), confirmed via the PRO record in OLS. This PR ID is also the one consistently used elsewhere in `cl-edit.owl` for CD14 (e.g. in the lineage-negative gating axioms on `CL:0000037`, `CL:0000553`, `CL:0000611`, etc.).
- **Definition mirrors logical definition:** kept the text description in genus-differentia form, mirroring the equivalence axiom, as required by the CL editors' guide.
- **References:** added the five OMIP PMIDs (OMIP-77, OMIP-87, OMIP-94, OMIP-101, OMIP-112) as `oboInOwl:hasDbXref` annotations on the `IAO:0000115` definition axiom. Existing definition xrefs were preserved per the issue's explicit instruction "Add these references but do not replace existing references".
- **No creator change:** these are existing terms, so no `dc:creator` was added (per the CLAUDE.md guidance not to add yourself as creator when editing existing terms).
