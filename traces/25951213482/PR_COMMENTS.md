# Revise intraepithelial lymphocyte and add intestinal IEL subclass

Addresses obophenotype/cell-ontology#3346.

## Rationale

The existing term `intraepithelial lymphocyte` (CL:0002496) had a definition and logical axiom that restricted IELs to the intestinal epithelium. As the issue notes, IELs are in fact found across multiple epithelial tissues (gastrointestinal, respiratory, reproductive, oral). This PR:

1. Broadens CL:0002496 to cover all mucosal epithelial tissues.
2. Introduces a more specific child term for the intestinal subset, preserving the previous intestine-scoped semantics.
