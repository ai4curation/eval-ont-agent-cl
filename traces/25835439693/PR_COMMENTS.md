# Revise `intraepithelial lymphocyte` and add `intestinal intraepithelial lymphocyte`

Addresses obophenotype/cell-ontology#3346.

## Summary

The existing `intraepithelial lymphocyte` (`CL:0002496`) restricted IELs to the intestinal epithelium in both its textual and logical definitions, but IELs are found in epithelia of multiple mucosal tissues (GI, respiratory, reproductive, etc.). This PR broadens `CL:0002496` and introduces a dedicated `intestinal intraepithelial lymphocyte` subclass for the intestinal-specific concept.

## Changes

### `CL:0002496` (intraepithelial lymphocyte) — broadened

- **Text definition** replaced with the wording supplied in the issue:
  > A tissue-resident lymphocyte located within the epithelial layer of mucosal tissues, particularly within the gastrointestinal, respiratory, and reproductive tracts. Characterised by permanent residency, this cell typically expresses CD103 (integrin alpha-E), which binds to E-cadherin on epithelial cells, enabling epithelial retention in both mice and humans. Phenotypically, IEL displays an activated, antigen-experienced state characterised by the constitutive expression of cytotoxic molecules (granzyme B, perforin) and innate-like receptors (such as NKG2D), enabling rapid, localised surveillance and immediate response to epithelial stress.
  - Note: corrected the obvious typo `ntegrin` -> `integrin`.
- **Logical definition** changed to use `epithelium` (`UBERON:0000483`) instead of `intestinal epithelium` (`UBERON:0001277`):
  - `'mature T cell' and ('located in' some 'epithelium') and ('capable of' some 'mucosal immune response')`
- **Definition xrefs** added (existing xrefs preserved per issue instructions):

- **Contributor** added: `https://orcid.org/0009-0000-8480-9277`

### `CL:9900000` (intestinal intraepithelial lymphocyte) — new term

Carries the original `CL:0002496` semantics so that the intestinal-IEL concept is not lost.

- **Text definition**: "A T cell that is located in the intestinal epithelium and is capable of a mucosal immune response."
