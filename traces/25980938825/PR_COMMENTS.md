### Scope decision
Per @Caroline-99's comment in the issue, CD14-negative was **not** added to [CL:0001056](http://purl.obolibrary.org/obo/CL_0001056) (dendritic cell, human), since several human DC subsets (e.g., dermal DCs; PMID:23621371, PMID:34279540) do express CD14. The issue body explicitly lists only CL:0001057 and CL:0001058, so the scope here matches both the issue request and the curator's clarification.

## Rationale
- The `lacks_plasma_membrane_part` (CL:4030046) object property is the standard CL pattern for marker absence — it's already used in CL:0001058 for CD11c-negative, and broadly across CL (e.g., CL:0000037 hematopoietic stem cell, CL:0000553 lineage-negative cell).
- `PR:000001889` ("monocyte differentiation antigen CD14") is the correct PR term for CD14; verified by cross-referencing CL:0000037's textual definition, which lists CD14 among its lin-negative markers and uses `PR:000001889` in the corresponding `lacks_plasma_membrane_part` axiom.
- The OMIP papers cited in the issue all use CD14-negative gating to distinguish human DCs (both myeloid/cDC and pDC populations) from monocytes, supporting the addition for these two species-specific terms.
