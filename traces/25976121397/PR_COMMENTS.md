# PR Description: Add CD14-negative phenotype to human dendritic cell types

## Summary

This PR addresses issue #3163 by updating the class hierarchy of human dendritic cell terms to include CD14-negative phenotype and adding supporting references from flow cytometry standards (OMIP publications).

## Changes Made

### CL_0001057 (myeloid dendritic cell, human)

- **Textual Definition**: Updated from "A myeloid dendritic cell with the phenotype HLA-DRA-positive." to include "and CD14-negative"
- **Logical Definition**: Added `ObjectSomeValuesFrom(obo:CL_4030046 obo:PR_000001889)` to express "lacks CD14" in the equivalent classes
- **References**: Added PMID citations for five OMIP papers demonstrating CD14-negative gating strategy

### CL_0001058 (plasmacytoid dendritic cell, human)

- **Textual Definition**: Updated from "A plasmacytoid dendritic cell with the phenotype HLA-DRA-positive, CD123-positive, and CD11c-negative." to also include "and CD14-negative"
- **Logical Definition**: Added `ObjectSomeValuesFrom(obo:CL_4030046 obo:PR_000001889)` to express "lacks CD14" in the equivalent classes
- **References**: Added PMID citations for five OMIP papers demonstrating CD14-negative gating strategy

## Rationale

Human myeloid and plasmacytoid dendritic cells are consistently defined as CD14-negative in flow cytometry gating strategies, used to distinguish them from monocytes. The five OMIP (Optimized Multiplex Immunophenotyping) publications cited demonstrate this standard across multiple panels and years (OMIP-77, OMIP-87, OMIP-94, OMIP-101, OMIP-112).

### Note on CL_0001056 (dendritic cell, human)

Per reviewer comment from Caroline-99, the general human dendritic cell term (CL_0001056) was not modified to include CD14-negative status, as some tissue-specific DC subsets (e.g., dermal dendritic cells) are known to express CD14 (citations: PMID:23621371, PMID:34279540).
