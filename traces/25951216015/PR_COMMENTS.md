# Add abbreviation synonyms PBMC, WBC, RPE

Addresses [issue #3559](https://github.com/obophenotype/cell-ontology/issues/3559).

## Summary

Added three widely used cell type abbreviations as **exact synonyms** with the **abbreviation synonym type** (`OMO:0003000`) to support text-mining / LLM-based mapping of sample metadata strings to Cell Ontology terms.

| Term | CL ID | Synonym added | Scope | Type |
|------|-------|---------------|-------|------|
| peripheral blood mononuclear cell | CL:2000001 | `PBMC` | exact | abbreviation (OMO:0003000) |
| leukocyte | CL:0000738 | `WBC` | exact | abbreviation (OMO:0003000) |
| retinal pigment epithelial cell | CL:0002586 | `RPE` | exact | abbreviation (OMO:0003000) |

Each affected term also has a new `term_tracker_item` (`IAO:0000233`) annotation linking back to issue #3559.

## Rationale

- The submitter (working on LLM-based extraction of cell types from experimental sample metadata) reported that strings like `PBMC`, `WBC`, and `RPE` could not be mapped to CL because the abbreviations were not registered.
- @addiehl (CL maintainer, MEMBER) approved adding `PBMC` and `WBC` as exact synonyms.
- @scheuerm (COLLABORATOR) confirmed `RPE` is appropriate as a synonym for `retinal pigment epithelial cell`; based on common usage and parallelism with the other two abbreviations, it was also added as an exact synonym (e.g. "RPE cell" and "retinal pigment epithelial cell" are used interchangeably in the literature).
- All three synonyms are tagged with `OMO:0003000` (abbreviation), which is the existing CL pattern for marking abbreviations (e.g. `D2-MSN`, `iSPN`, `COP`, `GBC`, `VIC` use the same combination of `hasExactSynonym` + `OMO:0003000`).
