# Add CD14-negative phenotype to human myeloid and plasmacytoid DC terms

Addresses [issue #3163](https://github.com/obophenotype/cell-ontology/issues/3163).

## Summary of changes

Two terms updated in `src/ontology/cl-edit.owl`:

### CL_0001057 — myeloid dendritic cell, human
- Logical definition extended with `lacks_plasma_membrane_part some CD14` (PR:000001889 via CL:4030046).
- Textual definition updated:
  - Before: "A myeloid dendritic cell with the phenotype HLA-DRA-positive."
  - After: "A myeloid dendritic cell with the phenotype HLA-DRA-positive and CD14-negative."
- Definition xrefs: existing PMID:22343568 retained; added OMIP references (PMID:34260151, PMID:36470845, PMID:37254600, PMID:38343094, PMID:40095400).
- Added `term_tracker_item` (IAO:0000233) pointing to issue #3163.

### CL_0001058 — plasmacytoid dendritic cell, human
- Logical definition extended with `lacks_plasma_membrane_part some CD14` (PR:000001889), alongside the existing `lacks_plasma_membrane_part some CD11c`.
- Textual definition updated:
  - Before: "A plasmacytoid dendritic cell with the phenotype HLA-DRA-positive, CD123-positive, and CD11c-negative."
  - After: "A plasmacytoid dendritic cell with the phenotype HLA-DRA-positive, CD123-positive, CD11c-negative, and CD14-negative."
- Definition xrefs: existing PMID:22343568 retained; added the same OMIP references.
- Added `term_tracker_item` pointing to issue #3163.

### CL_0001056 (dendritic cell, human) — intentionally not modified
Per @Caroline-99's comment on the issue (citing PMID:23621371 and PMID:34279540), some human DC subtypes (e.g. dermal DCs, CD14-positive DC3) do express CD14, so the general human DC term must remain compatible with those subtypes. CD14-negativity is only added at the level of the more specific myeloid and plasmacytoid DC terms, matching the OMIP gating strategies.
