# Change CXCR3 relation on CL_0001041 to `has plasma membrane part`

Addresses issue #3382.

## Change

In `src/ontology/cl-edit.owl`, the equivalence axiom for [CL_0001041](http://purl.obolibrary.org/obo/CL_0001041) (CD8-positive, CXCR3-positive, alpha-beta regulatory T cell) was updated:

- **Before:** `... ObjectSomeValuesFrom(BFO_0000051 PR_000001207) ...` (has part some CXCR3)
- **After:** `... ObjectSomeValuesFrom(RO_0002104 PR_000001207) ...` (has plasma membrane part some CXCR3)

A `term_tracker_item` (IAO_0000233) annotation was also added linking the term to issue #3382.

## Rationale

CXCR3 ([PR_000001207](http://purl.obolibrary.org/obo/PR_000001207)) is a plasma-membrane chemokine receptor and is recorded as a cell-surface marker throughout CL. The [CL relations guide](../blob/master/docs/relations_guide.md#cell-surface-protein-markers) specifies that `has plasma membrane part` (RO_0002104) should be used for cell-surface protein markers. The previous use of `has part` was inconsistent with how CXCR3 is recorded on sibling terms.

Verification — all other terms whose equivalence axioms relate to PR_000001207 already use the correct relation:

| Term | Relation used for CXCR3 |
| --- | --- |
| CL_0000545 (T-helper 1 cell) | `RO_0002104` (has plasma membrane part) |
| CL_0000899 (T-helper 17 cell) | `CL_4030046` (lacks plasma membrane part) |
| CL_0000917 (CD8-positive, alpha-beta cytotoxic T cell) | `RO_0002104` |
| CL_0000546 (T-helper 2 cell) | `CL_4030046` |
| CL_0000918 | `CL_4030046` |
| CL_0001051 (CD4+, CXCR3-, CCR6- αβ T cell) | `CL_4030046` |
| CL_0001052 (CD8+, CXCR3-, CCR6- αβ T cell) | `CL_4030046` |

Only CL_0001041 was the outlier, which is now resolved.

## Issue author's additional note

The original issue also asked whether the use of `has part`/`lacks part` (rather than `has/lacks plasma membrane part`) on a number of PR terms — immunoglobulin iota chain (PR_000001858), immunoglobulin lambda-like polypeptide 1 (PR_000001859), c-Fos (PR_000007597), myeloperoxidase (PR_000010543), PU.1 (PR_000001944), RAG1 (PR_000003457), RAG2 (PR_000003460) — was intentional.

These proteins are not plasma-membrane proteins:

- Immunoglobulin iota chain and lambda-like polypeptide 1: components of the surrogate light chain / pre-B-cell receptor; can be cytoplasmic/intracellular at early developmental stages.
- c-Fos, PU.1: nuclear transcription factors.
- Myeloperoxidase: stored in azurophilic (primary) granules.
- RAG1, RAG2: nuclear recombinases.

Per the relations guide, `has plasma membrane part` is reserved for cell-surface markers; `has part` is therefore the correct relation for these intracellular markers and the distinction is intentional. This is noted in the issue comment but no further ontology change is needed for those terms.
