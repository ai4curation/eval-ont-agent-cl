# Add abbreviation synonyms PBMC, WBC, RPE

Addresses issue #3559.

## Summary

Adds three commonly used cell-type abbreviations as exact synonyms so that strings extracted from experimental sample metadata can be mapped back to the corresponding CL terms.

| Abbreviation | Term | CL ID |
|---|---|---|
| PBMC | peripheral blood mononuclear cell | CL:2000001 |
| WBC  | leukocyte                          | CL:0000738 |
| RPE  | retinal pigment epithelial cell    | CL:0002586 |

## Rationale

- The issue reporter is mapping LLM-extracted strings from sample metadata to CL and observed these three abbreviations failing to map. They are all in extremely common scientific use.
- `@addiehl` confirmed PBMC and WBC can be added as exact synonyms.
- `@scheuerm` confirmed RPE is appropriate as a synonym for retinal pigment epithelial cell.

## Synonym scope and type

All three are added as **exact** synonyms with the `OMO:0003000` (`abbreviation`) synonym type, matching the established pattern in `cl-edit.owl` (300+ existing uses of `OMO:0003000`, several of them with `hasExactSynonym` for letter-acronym forms — e.g. D2-MSN, iSPN, COP, GBC, VIC).

Note: leukocyte already had `"white blood cell"` as an exact synonym, so `WBC` slots in naturally next to it as the abbreviation form.
