# PR: Add CD14-negative to human dendritic cell terms

## Summary
Updated two human dendritic cell terms to include CD14-negative phenotype as requested in issue #3163:
- **CL_0001057** (myeloid dendritic cell, human)
- **CL_0001058** (plasmacytoid dendritic cell, human)

## Changes Made

### 1. Updated Textual Definitions
- **CL_0001057**: Changed from "A myeloid dendritic cell with the phenotype HLA-DRA-positive." to "A myeloid dendritic cell with the phenotype HLA-DRA-positive and CD14-negative."
- **CL_0001058**: Changed from "A plasmacytoid dendritic cell with the phenotype HLA-DRA-positive, CD123-positive, and CD11c-negative." to "A plasmacytoid dendritic cell with the phenotype HLA-DRA-positive, CD123-positive, CD11c-negative, and CD14-negative."

### 2. Updated Logical Definitions (EquivalentClasses)
Added `ObjectSomeValuesFrom(obo:CL_4030046 obo:PR_000001889)` to express CD14-negative in the logical definitions:
- **CL_0001057**: Added CD14-negative constraint
- **CL_0001058**: Added CD14-negative constraint (in addition to existing CD11c-negative)

### 3. Added References
Added five OMIP (Optimized Multicolor Immunofluorescence Protocols) references demonstrating standard human dendritic cell gating strategies with CD14-negative designation:
- OMIP-77 (PMID:34260151)
- OMIP-87 (PMID:36470845)
- OMIP-94 (PMID:37254600)
- OMIP-101 (PMID:38343094)
- OMIP-112 (PMID:40095400)

These were added as annotation assertions to both term definitions without replacing existing references (PMID:22343568).

### 4. Scope Note
Did NOT modify **CL_0001056** (dendritic cell, human) as correctly noted in the issue, since some human dendritic cells express CD14 (particularly tissue-specific subsets like dermal DCs). The specific myeloid and plasmacytoid DC populations are consistently CD14-negative in standard flow cytometry gating.
