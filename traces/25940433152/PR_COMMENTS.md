# Add CD14-negative phenotype to human myeloid and plasmacytoid DC terms

Addresses [issue #3163](https://github.com/obophenotype/cell-ontology/issues/3163).

## Summary of changes

Two terms in `src/ontology/cl-edit.owl` have been updated to record that the cell type lacks expression of CD14 (PR:000001889):

### CL_0001057 — myeloid dendritic cell, human

- **Logical definition**: added `lacks_plasma_membrane_part some PR:000001889` (CD14) to the `EquivalentClasses` axiom.
- **Textual definition**: changed from
  > "A myeloid dendritic cell with the phenotype HLA-DRA-positive."
  to
  > "A myeloid dendritic cell with the phenotype HLA-DRA-positive and CD14-negative."
- **Definition xrefs**: added PMID:34260151 (OMIP-77), PMID:36470845 (OMIP-87), PMID:37254600 (OMIP-94), PMID:38343094 (OMIP-101), PMID:40095400 (OMIP-112). Existing references (`GOC:add`, `PMID:22343568`) are preserved.
- **rdfs:comment**: extended to note that CD14-negative gating is used to distinguish DCs from monocytes (per OMIPs above), and to flag that some tissue-resident DC subsets (e.g., dermal DCs) may express CD14.
- **term_tracker_item**: added link to issue #3163.

### CL_0001058 — plasmacytoid dendritic cell, human

- **Logical definition**: added `lacks_plasma_membrane_part some PR:000001889` (CD14) to the existing `EquivalentClasses` axiom (which already lacked CD11c via the same relation).
- **Textual definition**: changed from
  > "A plasmacytoid dendritic cell with the phenotype HLA-DRA-positive, CD123-positive, and CD11c-negative."
  to
  > "A plasmacytoid dendritic cell with the phenotype HLA-DRA-positive, CD123-positive, CD11c-negative, and CD14-negative."
- **Definition xrefs**: same five OMIP PMIDs added, original xrefs preserved.
- **rdfs:comment**: extended with the same OMIP-derived gating rationale.
- **term_tracker_item**: added link to issue #3163.

## What is intentionally NOT changed

- **CL_0001056 — dendritic cell, human**: left untouched. Per @Caroline-99's comment on the issue, this general human DC term should NOT have a CD14-negative restriction, because some human DC subsets (notably dermal/tissue-resident DCs — PMID:23621371, PMC8292131) do express CD14. The dermal DC caveat is mentioned in the CL_0001057 comment instead.

## Rationale

- The relation used (`lacks_plasma_membrane_part`, `CL:4030046`) is the standard CL pattern for "negative" surface markers, per `docs/relations_guide.md`. It is already used in CL_0001058 for CD11c.
- CD14 = PR:000001889 (PRO "CD14 molecule"); verified against PRO/OLS and against existing usage of this PR ID for CD14 elsewhere in CL (e.g., in `CL_0000553` "Lin-negative" definition).
- OMIP PMID references were added per the issue request, without removing existing definition references.
- No `dc:creator` annotation was added because these are edits to existing terms, per project guidelines.
