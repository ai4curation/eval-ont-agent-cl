# PR Description: Add CD14-negative phenotype to human dendritic cell terms

## Summary

Added CD14-negative phenotype specification to two human dendritic cell terms (CL_0001057 and CL_0001058) in response to issue #3163. These cell types are consistently gated as CD14-negative in standard flow cytometry protocols to distinguish them from monocytes, which are CD14-positive.

## Changes Made

### CL_0001057 (myeloid dendritic cell, human)
- **Textual definition updated**: "A myeloid dendritic cell with the phenotype HLA-DRA-positive and CD14-negative."
- **Logical axiom enhanced**: Added `ObjectSomeValuesFrom(obo:CL_4030046 obo:PR_000001483)` to encode CD14 lack of expression
  - CL_4030046 = lacks_plasma_membrane_part (used for encoding negative markers)
  - PR_000001483 = CD14 protein
- **References added**: PMID:34260151, PMID:36470845, PMID:37254600, PMID:38343094, PMID:40095400 (OMIP protocols demonstrating CD14-negative gating)
- **Existing references preserved**: PMID:22343568, GOC:add

### CL_0001058 (plasmacytoid dendritic cell, human)
- **Textual definition updated**: "A plasmacytoid dendritic cell with the phenotype HLA-DRA-positive, CD123-positive, CD11c-negative, and CD14-negative."
- **Logical axiom enhanced**: Added `ObjectSomeValuesFrom(obo:CL_4030046 obo:PR_000001483)` to encode CD14 lack of expression
- **References added**: PMID:34260151, PMID:36470845, PMID:37254600, PMID:38343094, PMID:40095400 (OMIP protocols demonstrating CD14-negative gating)
- **Existing references preserved**: PMID:22343568, GOC:add

## Rationale

1. **Flow cytometry standards**: The five added OMIP references (OMIP-77, OMIP-87, OMIP-94, OMIP-101, OMIP-112) document standard gating strategies for human dendritic cell populations, all of which define DCs as CD14-negative to distinguish them from monocytes.

2. **Scope limitation**: CD14-negative was intentionally NOT added to the general human dendritic cell term (CL_0001056) because some tissue-specific human DC subsets (e.g., dermal DCs) may express CD14, as noted in the issue discussion and supporting literature.

3. **Logical representation**: The use of `lacks_plasma_membrane_part` (CL_4030046) is consistent with how other negative markers are encoded in the Cell Ontology (e.g., CD11c-negative is already encoded this way in CL_0001058).
